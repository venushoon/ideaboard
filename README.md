# 📋 나만의 아이디어 보드 (Ultimate)

학교 현장과 팀 협업을 위해 제작된 **실시간 온라인 포스트잇 게시판(SaaS형 웹 애플리케이션)**입니다. 
복잡한 가입 절차 없이 선생님은 구글 계정으로, 학생들은 6자리 코드로 즉시 입장하여 서로의 아이디어를 실시간으로 나눌 수 있습니다. PC, 태블릿, 전자칠판 등 모든 스마트 기기에서 완벽하게 작동합니다.

## ✨ 주요 기능 (Key Features)

* **🔐 하이브리드 인증 시스템 (Hybrid Auth)**
  * **선생님 (호스트):** 구글 로그인(OAuth)을 통해 나만의 프라이빗 보드 목록을 생성하고 관리합니다.
  * **학생 / 게스트:** 회원가입 없이 6자리 '참여 코드'만 입력하여 다이렉트로 보드에 입장합니다.
* **👑 마스터 대시보드 (Master Admin Panel)**
  * 지정된 마스터 관리자는 서버에 생성된 모든 보드를 조회하고 강제 삭제할 수 있는 중앙 통제 권한을 가집니다.
* **🎨 3가지 레이아웃 지원**
  * `캔버스 (Canvas)`: 자유롭게 포스트잇을 드래그 앤 드롭하며 무한히 화면을 확장할 수 있습니다.
  * `담벼락 (Wall)`: 핀터레스트(Masonry) 스타일로 포스트잇이 빈틈없이 자동 정렬됩니다.
  * `컬럼 (Column)`: 패들렛 스타일처럼 주제(섹션)별로 단을 나누어 의견을 분류합니다.
* **👆 완벽한 터치 호환 & 스마트 스크롤 엔진**
  * 태블릿 및 전자칠판의 터치 환경을 완벽 지원합니다.
  * 캔버스 모드에서 화면 가장자리로 포스트잇을 끌고 가면 자동으로 화면이 확장되는 **Edge-Panning 알고리즘**이 탑재되어 있습니다.
* **📄 스마트 PDF & 이미지 내보내기**
  * `이미지 캡처`: 전체 보드의 조감도를 고화질 JPEG(용량 최적화)로 내보냅니다.
  * `스마트 PDF`: A4 세로 크기에 맞춰 포스트잇을 핀터레스트 형식으로 정렬하고, 공간이 부족하면 **자동으로 다음 페이지로 넘겨주는(Pagination) 지능형 보고서 엔진**을 탑재했습니다.
* **💾 데이터 및 용량 관리**
  * 15일 보관 후 영구 삭제되는 **휴지통 기능**과 사진/파일만 일괄 삭제하는 **용량 정리 기능**으로 무료 서버 환경(1GB)에서도 평생 쾌적하게 사용할 수 있습니다.

<br>

## 🛠 기술 스택 (Tech Stack)

* **Frontend:** HTML5, CSS3 (Vanilla), JavaScript (ES6+ Module)
* **Backend (BaaS):** Firebase Realtime Database (실시간 동기화), Firebase Authentication (구글 로그인)
* **Libraries:** * `html2canvas`, `jspdf` (이미지 및 PDF 변환)
  * `mobile-drag-drop` (터치 기기 드래그 앤 드롭 폴리필)

<br>

## 🚀 설치 및 시작하기 (Getting Started)

이 프로젝트는 별도의 Node.js 서버나 빌드 과정 없이, 순수 정적 파일(Static Files)로 구성되어 있어 GitHub Pages 등을 통해 즉시 무료로 배포할 수 있습니다.

### 1. Firebase 설정
1. [Firebase Console](https://console.firebase.google.com/)에서 새 프로젝트를 생성합니다.
